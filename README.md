# netflix-content-analysis
Analysis of 8,807 Netflix titles using Python and SQL
## Key Findings 
69.6% movies vs 30.4% TV shows
US leads with 2,818 titles; India is the fastest growing
Content additions peaked in 2019 before the COVID-19 slowdown
60%+ of content targets adult audiences - family content is an underrepresented opportunity
## Tools 
Python, Pandas, SQL, Matplotlib, Seaborn, Google Colab
